# 🍜 餐廳點餐系統

一套完整的餐廳點餐與後台管理系統，純前端實作，無需伺服器，資料儲存於瀏覽器 localStorage。

## ✨ 功能特色

### 顧客點餐端
- 📋 **菜單瀏覽** — 分類篩選（飯類、麵類、小吃、飲料）+ 關鍵字搜尋
- 🛒 **購物車** — 加入商品、調整數量、移除品項，資料持久化（重整不遺失）
- 🪑 **桌號 / 姓名 / 人數** — 下單前填寫顧客資訊
- 📝 **品項備註** — 每道菜可單獨填寫備註（例：不要蔥）
- 📝 **整單備註** — 整筆訂單的額外說明
- 🌶️ **選項支援** — 辣度、甜度、麵條種類等可選項目
- 💳 **付款方式** — 現金、刷卡、LINE Pay、轉帳
- 🎉 **下單確認** — 訂單送出後顯示訂單編號
- 🖨️ **列印收據** — 開啟列印視窗輸出收據

### 後台管理端（密碼保護）
- 📋 **訂單管理** — 查看所有訂單、依狀態篩選、推進訂單狀態
  - 狀態流程：待處理 → 製作中 → 可取餐 → 已完成
  - 可取消訂單、列印個別收據
  - 每 30 秒自動重新整理
- 🍽️ **菜單管理** — 新增 / 編輯 / 刪除菜品、上架 / 下架控制
- ⚙️ **系統設定** — 餐廳名稱、服務費、公告訊息、管理員密碼

## 🚀 快速開始

1. 直接用瀏覽器開啟 `index.html`（或部署至任何靜態網頁主機）
2. 點餐頁面即可使用
3. 點擊右下角 ⚙️ 進入後台，預設密碼：`admin123`

## 🔧 技術規格

- **純原生 HTML / CSS / JavaScript**，無任何外部依賴
- **localStorage** 持久化儲存（菜單、訂單、設定、購物車）
- **PWA 支援**（manifest.json，可加入主畫面）
- **RWD 響應式設計**，支援手機、平板、桌機
- **無障礙設計**（ARIA 標籤、鍵盤操作）

## 📁 檔案結構

```
├── index.html      # 主頁面（顧客點餐 + 後台管理）
├── app.js          # 應用程式邏輯
├── style.css       # 樣式表
├── manifest.json   # PWA 設定
└── README.md       # 說明文件
```

## 🔐 後台入口

- 點擊頁面右下角的 ⚙️ 圖示
- 輸入管理員密碼（預設：`admin123`）
- 可在「設定」頁面更改密碼

## 📱 部署建議

可部署至以下平台（免費）：
- [GitHub Pages](https://pages.github.com/)
- [Netlify](https://netlify.com/)
- [Vercel](https://vercel.com/)
- 任何靜態網頁主機

> ⚠️ **注意**：資料儲存於瀏覽器 localStorage，清除瀏覽器資料會遺失訂單與設定。如需跨裝置同步，需接入後端 API。
